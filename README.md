# ÖBB Ticket Preview — an "external library integration" kata

A tiny React app that displays purchased ticket details.

>Used for training purpose within [Better Engineering Community](https://www.withnik.com/community) founded by [Nik Sumeiko](https://www.linkedin.com/in/niksumeiko/).

## Spin it up

```bash
npm install
npm run start                      # start the app
npm run test:unit                  # via vitest
npm run test:integration           # playwright component test
```
